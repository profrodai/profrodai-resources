# 11 · Monitoring and evaluation (class notebooks, 23 November 2026)

Four notebooks for the ITAM class of 23 November 2026, all about Lucy's ice cream shop and an agent that says "Reserved!" when it may not have reserved anything. Run the cells of one notebook in order, top to bottom. Do the notebooks in the order 01 to 04.

| Notebook | What it is |
|---|---|
| `ITAM-Agentic-Observability-01-2026.ipynb` | Self-paced. Record what an agent did (trace, span, event, metric) before deciding why it went wrong. |
| `ITAM-Agentic-Observability-02-2026.ipynb` | Self-paced. Turn the evidence into a diagnosis, and check whether a new policy is actually better. Needs the ideas from notebook 1. |
| `ITAM-03-Calibrating-an-LLM-Judge.ipynb` | 40 to 45 minutes. Write a grading rule with observable criteria and test a judge against reference decisions. |
| `ITAM-04-Evaluating-a-Reservation-Agent.ipynb` | 45 to 55 minutes. Turn three business cases into a small evaluation suite and run two versions of the agent on identical cases. |

When a notebook asks you to paste a model ID, use `gpt-5.6-terra`.
