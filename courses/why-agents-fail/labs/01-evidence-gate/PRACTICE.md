# Evidence gate guided practice

## Objective
Deny a claim when any required source ID is missing and name the gap.

## Guided exercise
Run the complete and incomplete evidence sets, then remove each required ID one at a time.

## Project
Add duplicate supplied IDs and prove they do not satisfy a different missing requirement.

## Evidence
Provide pass/fail results, named missing sources, new regression test, and course gate output.

## Rubric
Pass: every claim requirement maps to distinct observed evidence. Revise: confidence, count, or duplicated evidence substitutes for the missing source.

## Accessibility
Compare the sets as plain text; no visual graph is required.

## Safety and cost
All claims and IDs are synthetic. No live model, private source, credential, or network is used.

## Verify
From the course directory run `make verify`.
