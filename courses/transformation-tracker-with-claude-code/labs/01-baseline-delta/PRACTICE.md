# Baseline delta guided practice

## Objective
Preserve an original time baseline and report improvement or regression without rewriting history.

## Guided exercise
Run a faster and slower observation, then explain the sign of each delta and why the original baseline remains visible.

## Project
Add a zero-baseline denial and a multi-week fixture that never edits prior observations.

## Evidence
Provide the preserved inputs, both directions of result, edge test, and course gate output.

## Rubric
Pass: regressions remain visible and historical inputs are unchanged. Revise: negative performance is hidden or the baseline is replaced.

## Accessibility
Use a text table and calculator; no chart or timed measurement is required.

## Safety and cost
Use invented minutes only. Do not add employee monitoring, personal productivity data, credentials, or provider calls.

## Verify
From the course directory run `make verify`.
