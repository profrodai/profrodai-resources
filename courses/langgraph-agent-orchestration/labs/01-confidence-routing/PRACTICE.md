# Confidence routing guided practice

## Objective
Make a typed routing boundary visible and prove both sides of its threshold.

## Guided exercise
Predict routes immediately below, at, and above `0.8`, then run the tests and explain why equality belongs to the tool route.

## Project
Add an invalid-confidence denial for values outside zero-to-one without importing LangGraph or a model provider.

## Evidence
Provide boundary-case outputs, the invalid-input test, and the course gate result.

## Rubric
Pass: threshold behavior and invalid ranges are explicit. Revise: routing depends on hidden state or a live model response.

## Accessibility
Use a written input/expected-route table; no graph visualization is required.

## Safety and cost
The exercise is an offline decision function. Do not add credentials, network calls, or claim it represents a production graph.

## Verify
From the course directory run `make verify`.
