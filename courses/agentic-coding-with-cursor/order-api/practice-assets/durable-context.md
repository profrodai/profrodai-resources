# Order API durable context fixture

This is a tool-neutral fixture for the practice. It represents the durable project context a
learner would configure in their own local coding tool; it is intentionally not a tracked agent
configuration directory.

- State the observable behavior and its acceptance test before editing.
- Keep a behavior change to its named source and test files.
- Never add network calls, credentials, real customer data, or a paid-provider requirement.
- When an input changes output, write an example that distinguishes it from the existing call.
